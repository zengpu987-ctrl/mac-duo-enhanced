# Mac Duo Android（安卓版）

把 MacBook 上的「合盖折叠玻璃动画」带到安卓手机：屏幕内容会随折叠角度向后倾斜、模糊、变暗。

## 效果

- **折叠屏手机**：自动读取铰链角度传感器（`Sensor.TYPE_HINGE_ANGLE`），合上屏幕时动画自动触发。
- **普通直板手机**：没有铰链，用 App 里的滑块手动驱动折叠角度，同样能看到倾斜 + 磨砂模糊 + 渐暗效果。
- 点击穿透：动画覆盖层不拦截触摸，下面的 App 仍可操作。

## 实现方式

1. 用 `MediaProjection` 截取当前屏幕一帧。
2. 把截图上传到 OpenGL 纹理。
3. 用顶点着色器绕屏幕下边缘做 3D 倾斜，用片段着色器做随高度增强的模糊与变暗。
4. 铰链角度 / 滑块实时驱动折叠角度。

## 构建与安装

用 Android Studio 打开本目录（`android/`）即可，Gradle 会自动同步并构建：

1. `File → Open` 选择 `android` 目录。
2. 连接手机或模拟器，点击 Run。
3. 首次运行会依次申请：通知、悬浮窗（显示在其他应用上层）、屏幕录制权限。
4. 点击「开始 / 重新捕捉屏幕」，然后拖动滑块（或折叠屏幕）看效果。

需要 Android 8.0（API 26）及以上；折叠屏铰链传感器需要 Android 11（API 30）及以上。

## 权限说明

- `SYSTEM_ALERT_WINDOW`：显示全屏动画覆盖层。
- `FOREGROUND_SERVICE_MEDIA_PROJECTION`：持续捕获屏幕。
- `POST_NOTIFICATIONS`：前台服务通知。

## 已知限制

- 当前为「截图帧」模式（类似 Mac 版关闭实时画面），不会持续录屏，因此不会出现屏幕回授。
- 不同机型的截图方向可能略有差异；如果画面上下颠倒，把 `DuoRenderer` 里的 `flipVertically` 去掉即可。
- 出于隐私，系统在录屏时可能隐藏部分敏感界面。
